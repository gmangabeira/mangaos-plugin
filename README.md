# MangaOS Plugin

Claude Code plugin providing 20 slash commands for the MangaOS marketing operating system.

## Commands

| Command | Description |
|---|---|
| `/mangaos:tasks` | View or modify the marketing task board |
| `/mangaos:learn` | Synthesize conversation insights to long-term memory |
| `/mangaos:ops` | Run the marketing project manager ops snapshot |
| `/mangaos:research` | Run a market research task using the research agent |
| `/mangaos:startup` | Force-run all MSE ops cadences on demand |
| `/mangaos:watch-queue` | Check the dispatch queue and execute pending tasks |
| `/mangaos:handoff` | Manage cross-agent handoff packets |
| `/mangaos:init-project` | Initialize a new MangaOS project workspace |
| `/mangaos:designer` | Produce visual assets using the designer agent |
| `/mangaos:think` | Perspective shift and problem resolution |
| `/mangaos:council` | Spin up a 5-advisor council to pressure-test a decision |
| `/mangaos:swarm` | Spawn a swarm of user persona agents |
| `/mangaos:blog-publish-run` | Final publish step for a blog article |
| `/mangaos:blog-refresh-run` | Run the full SEO refresh pipeline for a blog article |
| `/mangaos:run-task` | Execute the task delegation workflow for a task ID |
| `/mangaos:run-ce-stage` | Execute a Content Engine pipeline stage |
| `/mangaos:enrich-tasks` | Enrich task board fields from campaign briefs |
| `/mangaos:sync-vps-skills` | Sync skills to VPS containers |
| `/mangaos:branded-deck` | Create a branded presentation deck |
| `/mangaos:social-graphic` | Create a branded social media graphic |
